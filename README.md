# Comunicación RS232 - UART

## Descripción

En este proyecto se presenta el desarrollo de una práctica de laboratorio sobre comunicación serial UART utilizando tarjetas Raspberry Pi Pico y programación en MicroPython.

Durante la práctica se analizaron diferentes configuraciones de comunicación UART, observando mediante un osciloscopio la transmisión de caracteres y realizando mediciones de tiempo de bit. Posteriormente, se implementó la comunicación entre dos microcontroladores y finalmente se realizó la transferencia de archivos de texto mediante UART.

## Objetivos

- Comprender el funcionamiento de la comunicación serial UART.
- Analizar la estructura de una trama UART.
- Medir experimentalmente el tiempo de transmisión de los bits.
- Implementar la comunicación entre dos Raspberry Pi Pico.
- Realizar transmisión y recepción de caracteres.
- Implementar un mecanismo de confirmación mediante ACK.
- Transferir archivos de texto entre dos microcontroladores.
- Analizar el efecto del intervalo de transmisión sobre la pérdida de datos.

## Hardware utilizado

- Raspberry Pi Pico 2 W
- Raspberry Pi Pico
- Pantalla OLED
- Osciloscopio digital
- Cables de conexión
- Computador

## Software utilizado

- MicroPython
- Thonny
- Osciloscopio digital para las mediciones de las señales UART
